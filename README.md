# real2twin_showcase

Public-facing pages of the Real2Twin project for Etteln: the landing page, the village map and a progress page. Deployed by Cloudflare Pages from this repository (no build step, output directory is the repository root).

This repository holds only material that is safe to publish: no ALKIS or LoD2 files, no photos, no partner data, no keys or tokens. Content comes from the main project repository at milestones through `publish_showcase.ps1`, never by copying whole folders.
